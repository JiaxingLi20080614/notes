四条硬结论：

  1. sizeof 算的是字节数，不是元素个数；sizeof(int)=4、sizeof(char)=1、sizeof(double)=8。
  2. sizeof 是操作符不是函数，所以 sizeof x 合法，但习惯写 sizeof(x)。

  4. double 用 scanf("%lf")，写成 %f 读出来是乱码。这是选择题和编程题都爱考的坑。

P19–P20变量：这条不注意，编程题会静默丢分

局部变量不初始化，值是随机的垃圾值，不是 0。

int sum;        // 函数内的局部变量：值不确定
int sum = 0;    // 正确写法

只有全局变量和 static 变量才会自动初始化为 0。

为什么特别强调：循环累加（sum += x）、计数器（count++）忘了写 = 0，代码能编译、能运行、不报错，只是输出结果是一串莫名其妙的大数。考场上这类 bug 最难发现，因为你以为自己逻辑对了。

全局变量定义在函数外，作用域是整个文件；局部变量定义在函数内，出了大括号就失效。同名时局部优先。

第三组 · P21–P24 操作符 必看 · 真题主战场

P21算术操作符 编程题命根子

① 整数除法会截断

7 / 2     // 结果 3，不是 3.5！小数部分直接丢弃
7.0 / 2   // 结果 3.5（有一个操作数是浮点，结果才是浮点）
7 % 2     // 结果 1，取余

判断整除用 n % 3 == 0，判断奇偶用 n % 2 == 0。友好数、能被 3 整除的数，这些真题全靠它。

② 取余只能用于整数

7.5 % 2 是编译错误，浮点不能取余。

③ 负数取余的符号跟被除数一致

-7 % 2   // -1
7 % -2   // 1

P22赋值与复合赋值 真题第 6 题原题

2024 真题第 6 题：

int a = 5, b = 10;
b *= a += 2;
printf("%d %d", b, a);   // 输出：70 7

复合赋值是右结合的：先算 a += 2 → a = 7；再算 b *= 7 → b = 70。

复合赋值家族：+= -= *= /= %= >>= <<= &= |= ^=。记住它们优先级很低（仅高于逗号），且从右往左结合。

P23++ 与 -- 选择高频

int a = 5;
printf("%d", a++);   // 输出 5 —— 先用后加，之后 a 变 6
int b = 5;
printf("%d", ++b);   // 输出 6 —— 先加后用，b 也是 6

未定义行为（考场上见到就选"结果不确定"）：

printf("%d %d", x++, x);   // 同一表达式里又改又读，C 标准未规定求值顺序
a = i++ + ++i;             // 同样未定义

不同编译器结果不同，真题如果出这种题，答案就是"取决于编译器"或"未定义"。

P24强制类型转换

(int)3.14   // 3
(int)3.9    // 3 —— 截断，不是四舍五入
(double)5   // 5.0

想四舍五入的正确写法：(int)(3.9 + 0.5) = 4。

隐式转换：不同类型混合运算时，小的自动转大的（int → double）。5 / 2.0 得 2.5，因为 5 被提升成 5.0。

第四组 · P25–P29 printf 与 scanf 全场最高频

P25–P26格式符与域宽 2024 真题第 4、5 题

格式符完整表

格式符用途格式符用途
%d十进制整数%s字符串
%c单个字符%p地址（十六进制）
%ffloat / printf 的 double%x %X十六进制整数
%lfdouble（scanf 必须）%o八进制整数

域宽与精度（真题核心）

printf("%3d", 48);     // " 48"  —— 宽度 3，右对齐，左边补空格
printf("%-3d", 48);    // "48 "  —— 左对齐
printf("%03d", 48);    // "048"  —— 补 0
printf("%5.1f", 3.14159);  // "  3.1"  —— 总宽 5，保留 1 位小数
printf("%.0lf", 2.5);  // "3"    —— 保留 0 位，四舍五入

2024 真题第 4 题：输入字符 0，执行 scanf("%c", &x); printf("%3d", x);

%c 读到的是字符 '0'，其 ASCII 值是 48；%3d 宽 3 右对齐 → 输出 " 48"（两个前导空格）。

2024 真题第 5 题：要输出 3，scanf("%lf",&a); printf("%.0lf",a); 可输入的范围是 2.5 ~ 3.4（%.0f 四舍五入）。

P28–P29scanf 的三个坑 2024 真题第 7 题

坑 1：%c 不跳过空白字符（%d 会跳过）

2024 真题第 7 题：输入 1 2 3，执行 scanf("%c%c%c", &a, &b, &c)

三个 %c 依次读到 '1'、' '、'2' —— 中间的空格被当成字符读进去了。如果用 %d 则会自动跳过空格。

解法：写成 scanf(" %c", &x)，在 %c 前加一个空格，即可跳过前面的空白。

坑 2：必须加 &（取地址）

int a;      scanf("%d", &a);     // 正确
char s[10]; scanf("%s", s);      // 正确 —— 数组名本身就是地址，不加 &
int a;      scanf("%d", a);      // 错误，运行时崩溃

坑 3：scanf 的返回值

int n = scanf("%d %d", &a, &b);  // n = 成功读入的变量个数
while (scanf("%d", &x) == 1) { ... }        // 常用：读到非法输入为止
while (scanf("%d", &x) != EOF) { ... }      // EOF = -1

这个返回值是「读到 0 为止」那类编程题最优雅的写法，写进你的模板里（见文末模板 2）。

P27scanf 在 VS 下的报错 不看视频

VS 会提示 scanf 不安全。在源文件第一行写：

#define _CRT_SECURE_NO_WARNINGS 1

或者改用 scanf_s。考试注意：答题纸上要写标准 C 的 scanf，不是 scanf_s。

第五组 · P30–P34 分支结构

P30if 语句 两个坑

坑 1：把 == 写成 =

if (a = 1)   // 永远是真！这是赋值，不是比较
if (a == 1)  // 正确

反过来写能防这个错：if (1 == a) —— 万一漏写一个等号，编译器直接报错。

坑 2：悬空 else

if (a == 1)
    if (b == 1) printf("x");
else printf("y");       // 这个 else 属于内层 if，不是外层的！

else 总是和最近的、未配对的 if 结合，与缩进无关。建议大括号永远写上。

P31关系操作符与条件操作符

  • 关系：> >= < <= == !=，结果是 1（真）或 0（假）。
  • 不能写 a < b < c —— 它会先算 a<b 得 0 或 1，再拿这个 0/1 和 c 比。正确写法：a < b && b < c。
  • 三目运算符：max = (a > b) ? a : b; —— 一行代替 if-else，写代码很省事。

P32–P33逻辑操作符 2024 真题第 8 题

2024 真题第 8 题：if (a<b && c>b || a>b && b<c)，其中 a=5, b=0, c=3，结果是？

&& 优先级高于 ||，所以等价于 (a<b && c>b) || (a>b && b<c)。

代入：(5<0 && 3>0) = 假；(5>0 && 0<3) = 真 → 整体为真。

短路求值（必考细节）

  • &&：左边为假，右边根本不会执行。
  • ||：左边为真，右边根本不会执行。
int a = 0, b = 5;
if (a != 0 && b / a > 1)   // 安全！a==0 时右边不执行，不会除零

优先级完整顺序（从高到低）：

!  →  算术(* / % > + -)  →  关系(> < == ...)  →  &&  →  ||  →  赋值(= += ...)

只记一句就够：单目 > 算术 > 关系 > && > || > 赋值。

P34switch 语句

switch (表达式) {        // 表达式必须是整型（int/char）
    case 1: 语句; break; // break 不能漏
    case 2: 语句; break;
    default: 语句;       // 可选，放哪都行
}
  • 漏掉 break 会穿透到下一个 case 继续执行。
  • case 后面必须是整型常量，不能是变量，也不能写范围（不能写 case x>10）。

第六组 · P35–P42 循环 编程题骨架 · 必看

P35–P36while 循环 2025 真题框架

while (条件) {
    循环体;      // 条件为真就执行，直到条件为假
}

读到 0 为止的两类写法（2025 真题就是它）：

// 写法 A：死循环 + break（最直观，推荐写这个）
while (1) {
    scanf("%d", &x);
    if (x == 0) break;
    ...
}
// 写法 B：用 scanf 返回值（更优雅）
while (scanf("%d", &x) == 1 && x != 0) {
    ...
}

getchar() 逐字符读取，遇文件结束返回 EOF（即 −1）。经典框架：while ((ch = getchar()) != EOF)。

P37for 循环 2024 真题友好数用它

for (初始化; 判断条件; 调整) {
    循环体;
}
  • 执行顺序：初始化（只做一次）→ 判断 → 循环体 → 调整 → 判断 → …
  • 三部分都可省略，但两个分号不能省：for(;;) = 死循环。
  • 不要在循环体里修改循环变量，容易乱。

2024 真题：打印 1~100 中能被 3 整除的数

for (int i = 1; i <= 100; i++) {
    if (i % 3 == 0) printf("%d ", i);
}

P38do-while 循环

do {
    循环体;
} while (条件);      // 注意这个分号不能漏

与 while 的唯一区别：do-while 至少执行一次（先做再判断）。适用于"至少要输入一次"的场景。

P39break 与 continue

  • break：直接跳出整个循环。
  • continue：跳过本次循环剩下的部分，进入下一轮。

致命区别：在 while 里用 continue 会跳过"调整"步骤，可能死循环；在 for 里用 continue 会正常跳到调整部分，不会死循环。

int i = 0;
while (i < 10) {
    if (i == 5) continue;   // 死循环！i 永远停在 5
    i++;
}

P40循环的嵌套

for (int i = 1; i <= 9; i++) {         // 外层控制行
    for (int j = 1; j <= i; j++) {     // 内层控制列
        printf("%d*%d=%d ", j, i, i*j);
    }
    printf("\n");
}

真题友好数需要这个思路：对每一个数 a，先算出它的因子和 b，再验证 b 的因子和是不是等于 a。

P42随机数生成 低

#include <stdlib.h>
#include <time.h>
srand((unsigned int)time(NULL));   // 播种，main 开头只写一次
int x = rand() % 100;              // 0 ~ 99
int y = rand() % 100 + 1;          // 1 ~ 100

三道必背程序 考前盲写一遍

笔试编程题 20 分，从两份真题看，出题范围就在这三个模板的组合里。做到不用想就能敲出来。

模板 1 · 能被 3 整除的数（for + if）

#include <stdio.h>
int main() {
    for (int i = 1; i <= 100; i++) {
        if (i % 3 == 0) printf("%d ", i);
    }
    return 0;
}

模板 2 · 读到 0 为止，统计正数个数与负数的和 2025 真题

#include <stdio.h>
int main() {
    int x, pos = 0, negSum = 0;          // 必须初始化为 0！
    while (1) {
        scanf("%d", &x);
        if (x == 0) break;
        if (x > 0) pos++;
        else negSum += x;
    }
    printf("%d %d\n", pos, negSum);
    return 0;
}

模板 3 · 友好数（用函数有加分）2024 真题

#include <stdio.h>
int factorSum(int n) {
    int s = 0;
    for (int i = 1; i < n; i++)
        if (n % i == 0) s += i;
    return s;
}
int main() {
    for (int a = 1; a <= 10000; a++) {
        int b = factorSum(a);
        if (b > a && b <= 10000 && factorSum(b) == a)
            printf("%d %d\n", a, b);
    }
    return 0;
}

10000 以内的答案：220 284 / 1184 1210 / 2620 2924 / 5020 5564 / 6232 6368。b > a 是为了避免重复输出。

P11–P42 自测（12 题，答案可展开）

Q1：printf("%d", 7/2); 输出？

3。整数除法截断小数部分。想要 3.5 得写 7.0/2 或 7/2.0。

Q2：int a=5,b=10; b*=a+=2; printf("%d %d",b,a); 输出？

70 7。复合赋值右结合：先 a+=2 → 7，再 b*=7 → 70。（2024 真题第 6 题）

Q3：int a=5; printf("%d",a++); 与 int b=5; printf("%d",++b); 分别输出？

5 和 6。a++ 先用后加，++b 先加后用。

Q4：输入字符 0，scanf("%c",&x); printf("%3d",x); 输出？

" 48"（两个前导空格 + 48）。'0' 的 ASCII 是 48，%3d 右对齐宽 3。（2024 真题第 4 题）

Q5：输入 1 2 3，scanf("%c%c%c",&a,&b,&c); 后 a、b、c 分别是？

'1'、' '、'2'。%c 不跳过空白字符，中间的空格被读走了。（2024 真题第 7 题）要跳过空白写成 scanf(" %c", &x)。

Q6：a=5,b=0,c=3 时，a<b && c>b || a>b && b<c 为真还是假？

真。&& 优先级高于 ||：前一半假，后一半（5>0 且 0<3）真，整体真。（2024 真题第 8 题）

Q7：printf("%.0lf", 2.5); 与 printf("%.0lf", 2.4); 输出？

3 和 2。%.0f 是四舍五入，不是截断。

Q8：double d; scanf(_____, &d); 空白处填什么？

%lf。double 在 scanf 里必须用 %lf（printf 里 %f 和 %lf 都行）。这是最常见的一个失分点。

Q9：int sum; 然后直接 sum += x; 会怎样？

sum 的初始值是垃圾值，结果不可预测。必须写 int sum = 0;。只有全局变量和 static 才自动为 0。

Q10：int a=0,b=5; if(a!=0 && b/a>1) 会不会除零崩溃？

不会。&& 短路求值：左边 a!=0 为假，右边根本不执行。

Q11：下面代码有什么问题？int i=0; while(i<10){ if(i==5) continue; i++; }

死循环。i 加到 5 时执行 continue，跳过了 i++，i 永远是 5。（在 for 循环里则不会，因为 continue 会跳到调整部分）

Q12：strlen("c:\test\328") 的值是？（考点：转义字符）

逐字符拆：c : \t(1个) e s t \32(八进制转义，1个) 8 → 8。

关键：\ddd 最多吃 3 位八进制数字，8 不是八进制数字所以断开，单独算一个字符。

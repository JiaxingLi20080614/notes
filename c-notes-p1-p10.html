P1认识 C 语言

核心：C 是编译型语言。写出来的 .c 是源文件，不能直接运行，要经过 编译 → 链接 生成 .exe（可执行文件）才能跑。

流程：test.c —(编译)→ test.obj —(链接)→ test.exe

要记住的三句话：① C 语言是一门面向过程的、贴近底层的语言；② 它效率高、可移植性好，操作系统/嵌入式/单片机大量使用；③ 你后面学数据结构、操作系统都要用到它。

这一集考试基本不考，看个 5 分钟建立整体认知就行。

P3第一个 C 语言程序

#include <stdio.h>          // 1. 头文件：printf 在这里面

int main(void)              // 2. 主函数：程序入口
{
    printf("hello world\n"); // 3. 输出一句话
    return 0;                // 4. 正常结束
}

四条铁律：

  1. #include <stdio.h> 是预处理指令，不是语句，末尾不加分号。
  2. main 是程序唯一的入口，程序从 main 的第一行开始执行。
  3. 每条语句末尾必须有英文分号（中文分号是新手第一大坑）。
  4. 所有括号必须成对，缩进只是给人看的，不影响编译。

P4main 函数详解

记住这四点：

  • main 有且只能有一个。两个 main 程序直接报错。
  • 标准写法：int main(void) 或 int main(int argc, char* argv[])。
  • void main() 是不规范的写法，某些老教材（谭浩强早期版本）有，考试别写。
  • return 0; 表示程序正常结束；main 里省略 return，C99 之后编译器会自动补 return 0，但你一定要写。

真题挂接：选择题常问「以下说法正确的是」——正确项通常是"一个 C 程序有且只有一个 main 函数"。看到"可以有多个 main"直接判错。

P5printf 函数和库函数 必考

库函数：C 标准库已经写好的函数，直接用，但要引用对应的头文件。printf/scanf 在 stdio.h；strlen 在 string.h；数学函数在 math.h。

格式符含义示例输出
%d十进制整数 intprintf("%d", 10) → 10
%c单个字符 charprintf("%c", 65) → A
%f / %lffloat / double 小数printf("%f", 3.14) → 3.140000
%.1f保留 1 位小数（四舍五入）printf("%.1f", 3.14159) → 3.1
%3d占 3 个字符宽度，右对齐，不足补空格printf("%3d", 48) → ␣␣48
%-3d左对齐printf("%-3d", 48) → 48␣
%s字符串printf("%s", "abc") → abc

真题挂接（2024 卷）：

第 4 题：scanf("%c",&x); printf("%3d",x); 输入 0 → 输出 ␣␣48。这题同时考 P5（%3d 域宽）和 P7（'0' 的 ASCII 是 48）。

第 5 题：scanf("%lf",&a); printf("%.0lf",a); 要输出 3 → 输入 2.5~3.4 之间（四舍五入）。考 %.0lf = 保留 0 位小数即取整。

易错：printf 里格式符个数必须和后面的变量个数、类型一一对应。printf("%d %d", a) 少给一个参数会输出垃圾值，选择题就爱这么考。

P6关键字介绍 必考

关键字是 C 语言自己预留的词，不能拿来当变量名/标识符。C 语言一共有 32 个关键字。

必须认得的（考试够用）：

数据类型：char  short  int  long  float  double  signed  unsigned  void
控制语句：if  else  switch  case  default  while  do  for
          break  continue  goto  return
存储与修饰：auto  static  extern  register  const  volatile
构造类型：struct  union  enum  typedef
其他：sizeof

标识符命名规则（必背）：

  • 只能由字母、数字、下划线组成
  • 不能以数字开头
  • 不能是关键字
  • 区分大小写（sum 和 Sum 是两个东西）

真题挂接（2024 卷第 1 题，原题）：可用作合法用户标识符的是？
A. 2a —— 数字开头 ✗　B. void —— 关键字 ✗　C. -abc —— 含减号 ✗　D. _123 —— ✓ 正确答案

P7字符和 ASCII 编码 必考 · 全场最高频

核心认知：字符本质上是整数。计算机不存 'A'，只存 65。char 类型就是一个 1 字节的小整数。

字符ASCII 值说明
'\0'0字符串结束标志
'\n'10换行
空格32—
'0' ~ '9'48 ~ 57数字字符 ≠ 数字
'A' ~ 'Z'65 ~ 90—
'a' ~ 'z'97 ~ 122—

三个必会换算：

  • 字符转数字：'5' - '0' = 5（用 ASCII 相减）
  • 大写转小写：'A' + 32 = 'a'；小写转大写：'a' - 32 = 'A'
  • 判断大小写：if(c >= 'a' && c <= 'z')

真题挂接（2024 卷第 4 题）——这一集就是为这题准备的：

int x;
scanf("%c", &x);   // 用 %c 读入字符 '0'
printf("%3d", x);  // 用 %d 打印 → 输出的是 ASCII 值 48，不是 0

输入 0，输出 ␣␣48。为什么不是 0？因为 %c 读进来的是字符 '0'，它存进 int 就是 65 家族的 48。如果代码写的是 scanf("%d")，那输出才是 0。这一题把 %c 和 %d 的区别考到了骨头里。

另外一个高频坑（2024 第 7 题）：scanf("%c%c%c", ...) 输入 1 2 3，输出是 1 2（空格也被 %c 读走了）。%c 不跳过空白字符，%d 会跳过。这条在 P25–29 会细讲，先记住。

P8字符串和 \0

字符串用双引号，末尾自动补一个 '\0' 作为结束标志。这个 '\0' 是字符串存在的前提，不占可见内容但占空间。

char s1[] = "abc";     // 实际存了 4 个字节：'a' 'b' 'c' '\0'
char s2[] = {'a','b','c'};  // 只有 3 个字节，没有 '\0' → 不是字符串！
写法strlen（长度）sizeof（占字节）
char s[] = "abc";34（含 '\0'）
char s[10] = "abc";310（数组开了 10）
char s[] = {'a','b','c'};随机值（没 \0 停不下来）3

区分：strlen 数的是 '\0' 之前的字符个数（要 #include <string.h>）；sizeof 数的是实际占用的字节数。

真题挂接：选择题/填空常考 char s[]="hello" 的数组长度 = 6，strlen = 5。看到字符串就 +1，这是送分题。

P9转义字符（上）

转义字符 = 用反斜杠 \ 改变字符原本的含义。

写法含义要点
\n换行最常用
\t水平制表符相当于按 Tab
\0空字符（字符串结束）ASCII 是 0
\\表示一个反斜杠要打 \ 必须写两个
\' / \"单引号 / 双引号在字符串里打引号用
\a蜂鸣（响铃）不考，知道即可
\b退格光标回退一格，不删除
\r回车光标回到行首

关键理解：每个转义字符只算一个字符长度。所以 strlen("a\nb") = 3（a、\n、b），不是 4。

典型题：strlen("abc\n") = 4；strlen("a\\b") = 3（\\ 是一个字符）。

P10转义字符（中）· \ddd 与 \xhh

八进制转义 \ddd：反斜杠后跟 1~3 个八进制数字（0–7），表示对应的 ASCII 字符。

'\101'  → 八进制 101 = 十进制 65 = 字符 'A'
'\60'   → 八进制 60  = 十进制 48 = 字符 '0'
'\0'    → 八进制 0   = 十进制 0  = 空字符

十六进制转义 \xhh：反斜杠 + x + 十六进制数字。

'\x41'  → 十六进制 41 = 十进制 65 = 字符 'A'
'\x30'  → 十六进制 30 = 十进制 48 = 字符 '0'

经典陷阱题（必看）：strlen("c:\test\328") 等于多少？

逐个数：c : \t（转义，1 个）e s t \32（八进制转义，8 不是八进制数字，所以只吸收 32，8 单独算）8 → 共 8 个字符？数一遍：c、:、\t、e、s、t、\32、8 = 8。

要点：\ddd 最多吸收 3 个八进制数字，遇到 8、9 立刻停止。这类题几乎年年在各大 C 语言卷子里出现。

答案（做完再看）

1. 不要，预处理指令不是语句。
2. 有且只有一个。
3. 不是，标准写法是 int main(void)。
4. _123（2a 数字开头；void 是关键字；-abc 含减号）。
5. ␣␣5（右对齐占 3 位）。
6. 48 / 65 / 97。
7. '7' - '0'（等于 7）。
8. strlen = 3，sizeof = 4（含 '\0'）。
9. 3（a、\n、b）。
10. 都是字符 'A'（101 八进制 = 65；41 十六进制 = 65）。
